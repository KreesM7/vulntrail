# Roadmap

The 0.1 release provides real local Trivy execution and public-use evidence tools.
Future work requires separate review and evidence, not hidden promises of coverage:

- Native Linux/macOS real-engine and container integration checks.
- Additional sanitized backend-version and ecosystem fixtures.
- Accessible keyboard/screen-reader studies with representative users.
- Optional notifications/retention policies with explicit privacy controls.
- Verified engine/database transfer procedures and signed release provenance.
- Grype execution as a separately configured adapter, if validated demand exists.

Remote probing, privileged changes, public multi-user hosting, autonomous upgrades,
and malware containment are outside the current design.
